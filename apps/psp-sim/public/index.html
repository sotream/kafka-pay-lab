How to use this page
  1. Pick a preset to change how the fake payment provider behaves. Changes apply instantly to the next request.
  2. Create payments in the kafka-pay-lab dashboard (or use the load button there) and watch the request log below fill up.
  3. Fine-tune any setting with the controls, or force a single outcome by using a magic amount (see the table at the bottom).
